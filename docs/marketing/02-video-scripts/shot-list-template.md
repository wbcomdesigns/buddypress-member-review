## Visual Style Guidelines

### Screen Recordings

- Resolution: 1920x1080 (1080p)
- Browser: Chrome or Safari (clean appearance)
- No personal bookmarks visible
- Clean desktop if visible
- Cursor highlighting on (subtle)
- Zoom to relevant area when needed

### Screenshots

- PNG format
- Retina if possible (2x)
- Crop to relevant area
- Add subtle shadow/border
- Annotate with arrows when helpful

### Branding

- No competitor plugins visible
- No personal data visible
- Use demo/test member accounts
- Professional-looking profile photos (placeholder images OK)

## Recording Software

**Recommended:**
- Screen recording: OBS Studio, ScreenFlow, or Loom
- Screenshots: CleanShot X, Snagit, or native macOS
- GIF creation: Gifox or ScreenToGif

**Settings:**
- No webcam overlay for tutorials
- System audio only (no mic)
- Smooth scrolling enabled
- Mouse click indicators ON

## Audio Requirements

### Voiceover

- Professional narration (not text-to-speech)
- Conversational tone, not sales-y
- Clear pronunciation
- Consistent volume

### Background Music

- Upbeat but not overwhelming
- Royalty-free (Artlist, Epidemic Sound)
- No lyrics
- Volume: background level, voice is primary

---

## Video Specs for Export

### YouTube/Vimeo

- Format: MP4 (H.264)
- Resolution: 1920x1080 (1080p)
- Frame rate: 30fps
- Bitrate: 8-12 Mbps

### Social Media Ads

- Format: MP4 (H.264)
- Resolution: 1080x1080 (square) or 1080x1920 (vertical)
- Frame rate: 30fps
- Duration: 15s, 30s, 60s versions

### Website Embed

- Format: MP4 (H.264)
- Resolution: 1280x720 (720p) for faster loading
- Frame rate: 30fps
- Consider WebM as backup
