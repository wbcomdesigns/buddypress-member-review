# Installation & Setup Tutorial

## Video Details
- **Title:** How to Install and Configure BuddyPress Member Reviews
- **Duration:** 3:00
- **Purpose:** Walk new users through installation and basic configuration
- **Tone:** Instructional, clear, step-by-step
- **Target:** Site admins installing the plugin for the first time

---

## Script

### INTRO (0:00 - 0:10)

**VISUAL:** WordPress admin dashboard

**NARRATOR:** "This tutorial shows you how to install and configure BuddyPress Member Reviews in under three minutes."

**ON-SCREEN TEXT:** "Installation Guide"

---

### INSTALLATION (0:10 - 0:45)

**VISUAL:** WordPress Plugins > Add New

**NARRATOR:** "From your WordPress dashboard, go to Plugins, then Add New."

---

**VISUAL:** Search box with "member reviews" typed

**NARRATOR:** "Search for 'member reviews' and look for BuddyPress Member Reviews by Wbcom Designs."

---

**VISUAL:** Install Now button

**NARRATOR:** "Click Install Now, then Activate."

---

**VISUAL:** Menu appearing with Member Reviews item

**NARRATOR:** "You'll see a new 'Member Reviews' item in your admin menu."

---

### GENERAL SETTINGS (0:45 - 1:15)

**VISUAL:** Settings > Member Reviews > General tab

**NARRATOR:** "Click Settings to configure the plugin. Let's start with the General tab."

---

**VISUAL:** Highlight key settings

**NARRATOR:** "Choose who can leave reviews — all members, or only friends. Enable email notifications so members know when they receive a review."

---

**VISUAL:** Moderation toggle

**NARRATOR:** "Turn on 'Require Moderation' if you want to approve reviews before they appear."

---

**VISUAL:** Owner replies toggle

**NARRATOR:** "Enable 'Owner Replies' to let profile owners respond to their reviews."

---

**VISUAL:** Report threshold setting

**NARRATOR:** "Set the 'Report Threshold' — how many reports before a review is auto-hidden. Set to zero to disable auto-hiding."

---

### CRITERIA SETTINGS (1:15 - 1:45)

**VISUAL:** Criteria tab

**NARRATOR:** "Switch to the Criteria tab. This is where you define what members rate each other on."

---

**VISUAL:** Default criteria list

**NARRATOR:** "The plugin includes default criteria. You can edit, delete, or add new ones."

---

**VISUAL:** Adding new criterion

**NARRATOR:** "Click Add New, enter a label like 'Reliability' or 'Expertise', and save."

---

**VISUAL:** Showing multiple criteria

**NARRATOR:** "Add as many criteria as you need. Each one appears as a separate star rating in the review form."

---

### DISPLAY SETTINGS (1:45 - 2:15)

**VISUAL:** Display tab

**NARRATOR:** "The Display tab controls how reviews look."

---

**VISUAL:** Label customization

**NARRATOR:** "Customize labels — change 'Reviews' to 'Testimonials' or whatever fits your community."

---

**VISUAL:** Color picker for stars

**NARRATOR:** "Pick your star rating color to match your theme."

---

**VISUAL:** Profile header rating toggle

**NARRATOR:** "Choose whether to show ratings in the member directory and profile headers."

---

### TESTING (2:15 - 2:45)

**VISUAL:** Frontend member profile

**NARRATOR:** "Let's test it. Visit any member profile and click the Reviews tab."

---

**VISUAL:** Add Review button

**NARRATOR:** "Click 'Add Review' to open the review form."

---

**VISUAL:** Filling out review form

**NARRATOR:** "Rate each criterion, add a comment, and submit."

---

**VISUAL:** Review appearing on profile

**NARRATOR:** "If moderation is off, the review appears immediately. If it's on, it goes to the moderation queue."

---

### WRAP UP (2:45 - 3:00)

**VISUAL:** Admin reviews list

**NARRATOR:** "Manage all reviews from the Member Reviews admin page. Approve, edit, or delete as needed."

**ON-SCREEN TEXT:** "Setup Complete"

---

**VISUAL:** Plugin documentation link

**NARRATOR:** "Check out our documentation for advanced features like the Top Members shortcode and template overrides."

**ON-SCREEN TEXT:** "docs.wbcomdesigns.com"
