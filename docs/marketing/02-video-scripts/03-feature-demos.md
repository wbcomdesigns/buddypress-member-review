## Production Notes

### Common Elements
- Use consistent mouse cursor
- 1-second pause after each action
- Fade transitions between shots

### Annotation Style
- Red circles for click targets
- Numbered steps for sequences

### Export Formats
- MP4 for website/YouTube
- GIF for documentation (under 15 seconds each)
