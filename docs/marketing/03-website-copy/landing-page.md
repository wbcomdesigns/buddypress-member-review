## FAQ Section

### Headline
**Common Questions**

**Does it work with BuddyBoss?**
Yes. Fully compatible with BuddyBoss Platform and BuddyBoss Theme.

**Can members review themselves?**
No. Members can only review other members — the button doesn't appear on your own profile.

**What happens to reviews if I switch modes?**
Data is preserved. Ratings hide in Testimonials mode but reappear if you switch back.

**Do I need the free plugin to use Pro?**
Yes. Pro is an addon that requires the free base plugin (v3.7.0+).

**Is there a trial?**
No trial, but we offer a 14-day refund policy if Pro doesn't meet your needs.

**Can members delete their own reviews?**
No. Only admins can delete reviews. Members can edit their own reviews if editing is enabled in settings.
