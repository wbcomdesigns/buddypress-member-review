## Tutorial Posts

### How-To
```
How to set up member reviews in 5 minutes:

STEP 1: Install the plugin
Go to Plugins > Add New > Search "member reviews" > Install > Activate

STEP 2: Configure basics
Settings > Member Reviews > General
- Choose who can review
- Turn on email notifications
- Enable owner replies

STEP 3: Set your criteria
Criteria tab — add what members rate each other on (Communication, Quality, Reliability, etc.)

STEP 4: Test it
Visit any member profile > Reviews tab > Add Review > Submit

That's it. Your community now has trust signals.

Free on WordPress.org: https://wordpress.org/plugins/bp-user-profile-reviews/
```

Feature spotlight: Top Members Shortcode
