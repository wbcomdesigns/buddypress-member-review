## Threads

### How Member Reviews Works (5-part thread)

**1/5**
```
How to add member reviews to your BuddyPress community:

A thread 🧵
```

**2/5**
```
1. Install from WordPress.org
   Search "member reviews" → Install → Activate

2. Configure settings
   Settings > Member Reviews > General
   - Who can review
   - Moderation on/off
   - Notifications
```

**3/5**
```
3. Set up criteria
   Define what members rate each other on.
   - Communication
   - Quality
   - Reliability
   - (Your own)

Each criterion gets its own star rating.
```

**4/5**
```
4. Let members review
   Visit any profile → Reviews tab → Add Review
   - Rate each criterion
   - Add written comment
   - Optional: stay anonymous

Reviews appear on profiles and in member directory.
```

**5/5**
```
5. Moderate as needed
   Admin dashboard shows all reviews.
   - Approve pending
   - Handle reports
   - Edit or delete

That's it. Trust signals for your community.

Free: wordpress.org/plugins/bp-user-profile-reviews/
```
