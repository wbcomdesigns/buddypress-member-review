# Sales Pages

HTML landing pages for Free and Pro versions with consistent Wbcom Designs branding.

---

## Files

| File | Description |
|------|-------------|
| `free-version.html` | Landing page for free WordPress.org plugin |
| `pro-version.html` | Landing page for Pro addon with all features |

---

## Design System

Both pages use consistent Wbcom Designs branding:

### Colors
| Color | Value | Usage |
|-------|-------|-------|
| Primary | `#1d76da` | Links, buttons, accents |
| Primary Hover | `#0e62c3` | Button hover states |
| Secondary | `#3c8ce6` | Light blue accents |
| Heading | `#153045` | All headings |
| Body Text | `#515b67` | Paragraphs |
| Muted Text | `#767676` | Secondary text |
| Border | `#e3e3e3` | Dividers, borders |
| Background | `#f6f6f6` | Light backgrounds |
| Pro Accent | `#1d76da` | Pro features highlight |
| Testimonials | `#00b894` | Testimonials mode color |
| Endorsements | `#0984e3` | Endorsements mode color |

### Typography
- **Font Family:** Outfit (Google Fonts)
- **Headings:** 600-700 weight
- **Body:** 400 weight, 1.6 line-height
- **Quotes:** Lora serif for testimonials

### Components
- Buttons: 10px border-radius, 12-16px padding
- Cards: 12-16px border-radius, subtle shadows
- Sections: 80-100px vertical padding

---

## How to Use

### Preview Locally
Open either HTML file directly in a browser to preview.

### Deploy to Website
1. Copy the HTML content
2. Create new page in WordPress
3. Paste into Code/HTML block
4. Or extract sections to use with page builder

### Customize
- Update image paths to match your server
- Replace `../images/` paths with actual URLs
- Verify all links before publishing
- Test responsive behavior on mobile
