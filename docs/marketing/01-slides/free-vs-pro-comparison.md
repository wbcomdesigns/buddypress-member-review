# Free vs Pro Comparison Slides

## Slide 1: Title

**BuddyPress Member Reviews**
Free vs Pro — Which is Right for You?

---

## Slide 2: The Free Version

**Everything You Need to Start**

Free includes:
- 5-star ratings
- Multiple rating criteria
- Written reviews
- Owner replies
- Review reporting
- Moderation queue
- Email notifications
- Top Members shortcode
- Template overrides

**Best for:** Communities testing reviews or with basic needs

[Visual: Screenshot of reviews tab]

---

## Slide 3: When Free Is Enough

**Stick with Free if you:**

- Run a hobby/interest community
- Want basic star ratings
- Have under 1,000 members
- Don't need API access
- Don't need custom review types

**Example:** Gaming community where members rate each other for helpfulness

---

## Slide 5: Pro Feature — Testimonials Mode

**When Stars Don't Fit**

Course platforms, coaching sites, and membership communities need stories — not scores.

Testimonials Mode removes star ratings. Members share experiences in words.

> "Sarah's coaching helped me land my first client within 3 weeks."
> — Student testimonial

[Visual: Testimonial on profile without stars]

---

## Slide 6: Pro Feature — Endorsements Mode

**LinkedIn-Style Skills**

Professional networks don't use star ratings. Rating a colleague "4.5 stars" is awkward.

Endorsements Mode lets members vouch for each other's skills:

```
[Leadership (12)] [Communication (8)] [WordPress (5)]
```

[Visual: Profile with skill tags]

---

## Slide 7: Pro Feature — Verified Badges

**Trust Signals That Matter**

Anyone can write a review. Verified badges prove it's authentic.

| Verification Type | How It Works |
|-------------------|--------------|
| Admin Verified | Manual marking |
| Tenure Verified | Auto-verify long-term members |

[Visual: Review with verified checkmark]

---

## Slide 8: Pro Feature — Flexible Criteria

**Rate on Anything**

Free gives you star ratings. Pro lets you choose:

- **Stars** — 1-5 scale
- **Thumbs** — Up/Down binary
- **Text** — Short text input

Plus weighted averages — "Quality" can count more than "Speed."

[Visual: Criteria builder screenshot]

---

## Slide 9: Pro Feature — REST API

**Connect Everything**

Full CRUD API for:
- Mobile apps
- External dashboards
- Third-party integrations

```
GET /wp-json/bupr/v1/reviews
POST /wp-json/bupr/v1/reviews
GET /wp-json/bupr/v1/members/{id}/rating
```
