# Messaging Guide

## Brand Voice

### Tone
- **Helpful** — We solve problems, not create hype
- **Direct** — Say what you mean, skip the fluff
- **Knowledgeable** — We understand BuddyPress communities
- **Grounded** — Real features, real benefits, no exaggeration

### What We Sound Like
```
"Star ratings work for restaurants. Your professional network needs endorsements."

"Reviews build trust. Verified reviews build more trust."

"Three modes because not every community is Yelp."
```

### What We Don't Sound Like
```
❌ "Revolutionary AI-powered review system transforms your community!"
❌ "Seamlessly leverage member reviews to unlock growth!!"
❌ "The ULTIMATE review solution you've been waiting for!!!"
```

## Words to Use

| Use | Instead Of |
|-----|-----------|
| "Build trust" | "Create engagement" |
| "Surface good members" | "Gamify your community" |
| "Members rate each other" | "Users submit feedback" |
| "Three modes" | "Flexible platform" |
| "Works with BuddyPress" | "Seamlessly integrates" |
| "Moderation tools" | "Powerful admin controls" |

## Words to Avoid

| Avoid | Why |
|-------|-----|
| Revolutionary | Overused, meaningless |
| Seamless | Every plugin claims this |
| Game-changing | Hyperbole |
| Leverage | Corporate jargon |
| Unlock | Implies locked content |
| Ultimate | Unprovable superlative |
| World-class | Meaningless |
