## FAQ Section

### Headline
**Questions? We've Got Answers**

**Can members review themselves?**
No. Members cannot review their own profiles. This prevents fake reviews and maintains credibility.

**How do I prevent fake or spam reviews?**
Use review moderation to approve reviews before they go live. Enable the reporting system so members can flag suspicious reviews. In Pro, use verified badges to highlight legitimate reviews.

**Will this work with my theme?**
Yes. The plugin works with any BuddyPress-compatible theme. It includes template overrides if you want to customize the design. Fully tested with BuddyBoss Platform and Theme.

**Can I customize what members rate each other on?**
Absolutely. Create custom rating criteria like "Communication," "Quality," "Speed," or anything relevant to your community.

**Do reviews appear in the activity stream?**
Yes. New reviews automatically post to BuddyPress activity feeds, increasing visibility across your community.

**What's the difference between Ratings, Testimonials, and Endorsements?**
- **Ratings:** Traditional 5-star reviews with written feedback
- **Testimonials:** Text-based recommendations without star ratings (like LinkedIn recommendations)
- **Endorsements:** One-click skill endorsements (like LinkedIn endorsements)

All three modes are available in Pro only.

**Can I import reviews from another system?**
Not automatically, but the Pro version includes a REST API that developers can use to import reviews programmatically.

**What happens if I cancel Pro?**
Your existing reviews remain visible, but Pro features (like endorsements, API access, and verified badges) stop working. The free features continue working normally.

**Do you offer refunds?**
Yes. We offer a 30-day money-back guarantee on all Pro purchases.

**How do I get support?**
Free version support is available through WordPress.org forums. Pro customers get priority email support with faster response times.

**Does this work with WooCommerce?**
This plugin reviews community members, not products. For product reviews, use WooCommerce's built-in review system.

**Can I limit who can leave reviews?**
Both the free and Pro versions include developer hooks (such as `bupr_can_user_review`) that let you add custom restrictions (e.g., only members who follow each other, only verified members, etc.).
