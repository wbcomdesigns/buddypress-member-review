# BuddyPress Member Reviews - Messaging Guide

## Brand Voice & Messaging Framework

Use this guide to maintain consistent messaging across all marketing materials.

---

## Brand Voice

### Tone Attributes

| Attribute | Description | Example |
|-----------|-------------|---------|
| **Helpful** | We guide, not push | "Which review mode fits your community?" |
| **Honest** | We admit what we're not | "Reviews aren't a magic bullet for engagement" |
| **Practical** | Real use cases, not theory | "Course creators show testimonials. Marketplaces show ratings." |
| **Community-first** | It's about members, not metrics | "Help members find who to trust" |
| **Direct** | No marketing fluff | "Three modes. Pick one." |

### Voice Do's and Don'ts

**DO:**
- Explain which features fit which use cases
- Use real community examples
- Acknowledge limitations
- Focus on member experience
- Keep it conversational

**DON'T:**
- Claim to be "revolutionary"
- Use generic trust/credibility buzzwords
- Oversell minor features
- Ignore the free version
- Use corporate jargon

## Feature-to-Benefit Translation

Always transform features into benefits using "so you can..." or "which means..."

| Feature | Benefit Translation |
|---------|---------------------|
| Three Review Modes | Match your community type, so ratings don't force-fit testimonials |
| Verified Badges | Members know reviews are authentic, which means higher trust |
| REST API | Build mobile apps, which means reviews work anywhere |
| Flexible Criteria | Create custom rating fields, so you can rate specific skills |
| Owner Replies | Profile owners respond, which means two-way conversations |
| Report System | Members flag problems, so you can catch abuse without watching 24/7 |
| Anonymous Reviews | Honest feedback without fear, which means more authentic reviews |
| Activity Integration | Reviews show in feeds, so members see reputation updates |

## Free vs. Pro Messaging

### When to Mention Free
```
✅ Social media posts (build awareness)
✅ WordPress.org screenshots
✅ Getting started guides
✅ Community forum responses
```

### When to Push Pro
```
✅ Feature comparison pages
✅ Email upgrade campaigns
✅ Sales conversations
✅ After user hits limitations
```

### Upgrade Triggers
```
User says: "I wish I could show text testimonials instead of ratings"
Response: "That's Testimonial Mode in Pro. Hide ratings, show stories."

User says: "I need reviews in my mobile app"
Response: "Pro includes full REST API for custom integrations."

User says: "How do I verify reviews are real?"
Response: "Pro has verified badges (admin, tenure, transaction)."

User says: "I need skills endorsements like LinkedIn"
Response: "That's Endorsement Mode in Pro. One-click skill vouching."
```
